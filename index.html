Theory & Key Rules

1

Let x equal the decimal

Write x = the recurring decimal, e.g. x = 0.7777...

$$x = 0.\dot{7}$$
2

Multiply to shift the repeat

Multiply by 10 per repeating digit, so the recurring parts line up exactly.

$$10^n x = \ldots .\dot{d}\dot{d}\ldots$$
3

Subtract & simplify

Subtract the original x so the recurring parts cancel, then solve and simplify.

$$10^n x - x = \text{integer}$$

Lesson Worked Examples

1. Let $$x = 0.\dot{7} = 0.7777\ldots$$

2. One recurring digit, so multiply by 10: $$10x = 7.7777\ldots$$

3. Subtract: $$10x - x = 7.7777\ldots - 0.7777\ldots \implies 9x = 7$$

$$\text{Final Result: } x = \frac{7}{9}$$

1. Let $$x = 0.\dot{1}\dot{8} = 0.181818\ldots$$

2. Two recurring digits, so multiply by 100: $$100x = 18.1818\ldots$$

3. Subtract: $$100x - x = 18.1818\ldots - 0.1818\ldots \implies 99x = 18$$

4. Simplify: $$x = \frac{18}{99} = \frac{2}{11}$$

$$\text{Final Result: } x = \frac{2}{11}$$

1. Let $$x = 0.4\dot{1} = 0.41111\ldots$$ (only the 1 recurs)

2. Shift past the non-recurring digit: $$10x = 4.1111\ldots$$

3. Shift one more so the recurring parts align: $$100x = 41.1111\ldots$$

4. Subtract: $$100x - 10x = 41.111\ldots - 4.111\ldots \implies 90x = 37$$

$$\text{Final Result: } x = \frac{37}{90}$$
